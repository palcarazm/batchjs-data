# Getting Started

Install the package and the driver for the database you want to use.

```sh
npm install batchjs-data
npm install mariadb         # MariaDB
npm install mysql2          # MySQL
npm install pg @types/pg    # PostgreSQL
```

## Database guides

The package includes database-specific reader and writer implementations for:

- [SQLite](/guide/sqlite)
- [PostgreSQL](/guide/postgresql)
- [MariaDB](/guide/mariadb)
- [MySQL](/guide/mysql)
